### 🚀 Featured Projects

**🌐 [Enterprise Network Performance Monitoring (NPM) Dashboard](https://github.com/ruchikalodhi/NPM_Dashboard)**
Full-stack platform (FastAPI + SQLAlchemy backend, React/TypeScript frontend) for real-time monitoring of Cisco IOS/IOS-XE devices over SNMP and SSH.
- Automated network topology discovery via LLDP/CDP walks
- SNMP trap-based incident management system
- AES-256-GCM encrypted configuration backups with SHA-256 integrity verification
- Integrated SSH command terminal for live device management

**🛡️ [ShieldAI – AI Threat Intelligence & Malware Detection Platform](https://github.com/ruchikalodhi/Malware-Detection-System)**
ML-based malware classification engine trained and benchmarked on the UNSW-NB15 network intrusion dataset.
- Random Forest classifier with SHAP explainability for evidence-backed verdicts
- MITRE ATT&CK enrichment for detection context
- Benchmarked six classifiers — Random Forest, XGBoost, SVM, Decision Tree, Logistic Regression, KNN
